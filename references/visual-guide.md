# 可视化规范

研报交付形态为单文件 HTML 页面，其中须含不少于四张图表。规范规定页面结构、图表类型与数据的映射规则、配色与标注要求。

## 一、页面结构

单文件 HTML，所有样式与脚本内联，不依赖外部资源，双击即可在浏览器中打开。页面自上而下分五个区块。

| 区块 | 内容 | 图表 |
|---|---|---|
| 报告头 | 公司名称、股票代码、报告日期、数据截止期、分析框架 | 无 |
| 核心结论 | 三到五句判断，以结论卡形式呈现，分层判断用两块并列 | 可选一张估值或经营概览图 |
| 分节正文 | 按研报模板的各章节展开，每节承载其核心图表 | 不少于四张 |
| 观察点 | 该盯什么、不该盯什么，表格形式 | 可含一张趋势图 |
| 数据来源 | 来源追溯表，含层级、来源名称、日期、定位、状态 | 无 |

页面顶部设固定导航条，点击跳转至各节。页面宽度控制在 1100 像素以内的居中栏，正文行高不低于 1.7，确保长文可读。

## 二、图表数量与类型映射

正文须含不少于四张图表，覆盖下列核心判断。图表类型按数据关系选定，不按美观偏好选定。

| 数据关系 | 图表类型 | 用于呈现 |
|---|---|---|
| 收入的构成与占比 | 环形图或堆叠条形图 | 各业务板块占比、境内外收入结构 |
| 变化的方向与幅度 | 分组柱状图 | 营收与净利的同比，公司自身跨期对照 |
| 同业同期的横向比较 | 分组柱状图或斜率图 | 公司与可比公司的营收、净利同比对照 |
| 时间序列的趋势 | 折线图 | 毛利率、净利率、汇兑损益的逐期变化 |
| 结构差异与缺口 | 瀑布图或对照条形图 | 主业缺口的绝对金额与新业务体量的对比 |
| 多指标的相对位置 | 雷达图或热力表 | 公司与同业在盈利能力、成长性、现金流上的分布 |
| 目标与现状的距离 | 进度条形图 | 市占率目标与当前水平的差距 |

**硬性要求**：

- 同业对照须单独成图，不得只在文字中表述。这是全文归因的基础，图形化后差异一目了然。
- 至少有一张图呈现时间序列，用于说明趋势而非单点。
- 至少有一张图呈现公司与同业的并列，用于区分行业性问题与个体问题。
- 饼图仅用于部分与整体的关系，且分块不超过五块。

## 三、配色规则

页面采用浅色底、深色字，保证打印与投影均可读。

涨跌配色遵循 A 股惯例：

- 上升、改善、增长：红色系（#c0392b 或 #d64541）
- 下降、恶化、下滑：绿色系（#1e8449 或 #27ae60）
- 中性、同比持平、无方向数据：灰蓝色系（#5d6d7e）

配色方案相反的情形（如欧美市场惯例的红跌绿涨）不适用于本技能。所有图表与表格中的涨跌标注须保持一致。

其他约定：

- 同一指标在不同图表中使用同一颜色，避免同类数据在两张图中颜色不同
- 同业对照图中，目标公司用饱和色，可比公司用低饱和色，以便快速定位
- 数据来源与注释用浅灰小字，与正文区分
- 不使用渐变、阴影、立体效果

## 四、标注要求

每个图表下方须有三行文字，缺一不可。

第一行，图表标题，说明它呈现什么关系，采用陈述句（如"2026 年上半年营收与净利同比：公司与可比公司对照"），不采用疑问句或"关于……的图"这类虚指结构。

第二行，数据来源，写明层级与文件名称（如"数据来源：各公司 2026 年半年度报告"）。

第三行，读图要点，用一到两句话说明该图支持什么判断。这一行是图表与分析之间的连接，缺了图表就只是装饰。

图表中的数值标注保留必要精度，正文取整。同比数据须标明正负号，负值以括号或减号明确表示。

## 五、结论卡与表格

核心结论以卡片形式呈现，每张卡一句判断，卡片左侧用色条标示判断性质：结构性风险用深绿，过渡期风险用灰蓝，阶段性困难用浅红。分层判断（如收入层面与利润层面结论不同）须用两张并列卡片，不得合并成一句。

观察点表格固定三列：观察点、看什么、说明什么。第三列须写明"恶化／改善"的判定方向，不能只有指标名称。

数据来源表须完整呈现来源规范的七个字段，按层级排序，一级在前。状态列用文字标注，不用符号代替。

## 六、技术实现

使用内联 SVG 或轻量图表库（如 Chart.js 的 CDN 版本）绘制图表，若使用 CDN 须确认可离线访问的要求，优先选择内联 SVG 以保证脱离网络仍可正常显示。

字体使用系统中文字体栈，避免依赖外部字体文件。数字采用等宽字体栈，便于纵向比对。

页面须支持打印，打印样式下导航条与交互元素隐藏，图表强制分页不断裂。

## 七、可访问性

- 每张图表的含义须在正文中有对应文字表述，图形不是唯一信息载体
- 颜色不得作为唯一区分手段，涨跌须同时用正负号、箭头或文字标注
- 表格首行与首列使用表头样式
- 正文与背景的对比度不低于 4.5:1
