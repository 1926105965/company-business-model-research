# 数据来源规范

本规范限定调用本技能时允许使用的数据来源。凡不符合本规范的信息，不得作为论据进入研报。规范同时规定各层级来源的标注方式，以保证结论可追溯、可复核。

## 分级标准

数据来源分为三级。层级由两个维度决定：发布主体的权责（是否对信息真实性承担法律责任）与信息的可核验性（能否追溯到一份可下载、可比对的原件）。

| 层级 | 定义 | 使用方式 |
|---|---|---|
| 一级·原始披露 | 公司依法定程序披露的信息，监管部门发布的行政文件，官方统计机构发布的数据 | 可直接引为论据，须标注文件名称、发布主体、发布日期、具体页码或条目 |
| 二级·可核来源 | 具备资质的研究机构、行业组织、数据库商在其报告或数据产品中发布的信息 | 须标注机构名称、报告名称、发布日期；涉及财务数据时，须注明是否与一级来源交叉核对一致 |
| 三级·线索性来源 | 媒体、自媒体、社交平台、百科等渠道传播的信息 | 仅可用于发现线索，不得作为论据；若该信息最终被采纳，必须回一级来源核实，无法核实的按"未核实"处理，不入正文 |

判定一条信息来源属于哪一级，先问两个问题：发布主体是谁；能不能拿到原件。答不出发布主体，或拿不到可下载的原件，最高只能算三级。

## 一级来源清单

### 公司定期报告与法定披露

| 来源 | 可获取内容 | 检索位置 |
|---|---|---|
| 年度报告、半年度报告、季度报告 | 财务报表及附注、分行业分产品收入、产销量、毛利率、客户与供应商集中度、募集资金使用 | 巨潮资讯网（cninfo.com.cn）、上交所、深交所、北交所官网 |
| 审计报告 | 关键审计事项、审计意见类型 | 随年报披露 |
| 临时公告 | 重大合同、对外投资、股权变动、业绩预告与快报 | 同上 |
| 投资者关系活动记录表 | 管理层对经营形势的表述、对投资者提问的答复 | 巨潮资讯网"投资者关系"栏 |
| 招股说明书、配股／增发说明书 | 业务沿革、行业情况的详细描述 | 同上 |
| 公司章程与治理文件 | 治理结构、决策程序 | 同上 |

使用时须记录：报告名称（如《2025 年年度报告》）、报告期、披露日期、数据所在页码或表格编号。

### 监管与政府部门

| 来源 | 可获取内容 |
|---|---|
| 中国证监会及派出机构 | 行政处罚、监管措施、问询函与回复 |
| 证券交易所 | 纪律处分、年报问询函、监管函 |
| 国家统计局（stats.gov.cn） | 工业增加值、社会消费品零售总额、固定资产投资等宏观指标 |
| 海关总署（customs.gov.cn） | 进出口商品、分国别贸易数据 |
| 中国人民银行、国家外汇管理局 | 利率、汇率、外汇储备、国际收支 |
| 国家税务总局、财政部 | 税收政策、关税税则、财政收支 |
| 国家医保局 | 医保支付改革文件、集中带量采购公告与中选结果 |
| 地方医疗保障局、公共资源交易中心 | 地方集采公告、药品耗材招采结果 |
| 商务部 | 贸易政策、反倾销调查公告、对外投资统计 |

引用政策文件须写全文标题与发文号（如"医保发〔2024〕××号"），不能只写"有关政策规定"。

### 官方统计与标准

- 国家统计年鉴、各省统计年鉴
- 国家标准全文公开系统（openstd.samr.gov.cn）
- 中国裁判文书网（涉及诉讼事项时）

## 境外主体的数据获取路径

分析在中国香港、美国或其他境外市场上市的主体时，一级来源的获取位置与 A 股不同。下列路径均为官方披露平台，属一级来源。

| 上市地 | 官方披露平台 | 主要文件 |
|---|---|---|
| 中国香港 | 香港交易所披露易（hkexnews.hk） | 年报、中期报告、业绩公告、股东通函 |
| 美国 | 美国证券交易委员会 EDGAR 系统（sec.gov/edgar） | 10-K（年报）、10-Q（季报）、8-K（重大事项） |
| 其他境外市场 | 以当地交易所官方披露平台为准 | 年报与中期报告 |

**同时在内地与境外上市的主体**，以同一份合并报表为准，不得以两地披露的差异数字分别引用。若两地披露确实存在差异，须注明差异项与原因。

### 口径对齐的五项要求

境外披露与境内口径存在系统性差异，引用前须逐项对齐。**未对齐的数据不得与境内数据并列比较。**

**会计准则。** 中国香港多用香港财务报告准则或国际财务报告准则，美国用美国公认会计原则，境内用中国企业会计准则。三者对收入确认、金融资产计量与租赁的处理存在差异。涉及关键指标时须注明所据准则，并说明差异对指标的影响方向。

**报告期。** 美国公司的财年未必与日历年度一致。须标注财年区间（如"2026 财年，2025 年 7 月至 2026 年 6 月"），不得直接与境内主体的自然年度数据比较。

**币种与汇率。** 须注明原币种、换算所用汇率及换算时点。跨期比较时使用同一汇率口径，或同时给出原币种数据。

**指标口径。** 境外常用的 net income 可能包含少数股东权益，operating income 与境内的营业利润亦非同一口径。引用时须写明对应关系。少数股东权益占比较大的主体，该差异可能显著。

**披露频率。** 内地按季披露，中国香港的上市公司按半年披露中期报告，美国按季提交 10-Q。频率不同会影响趋势判断的形状，跨市场对照时须统一到可比的时间窗口。

### 监管与行业数据的境外来源

监管文件方面，美国以证券交易委员会的处罚与问询文件为准，中国香港以香港交易所与证券及期货事务监察委员会的公告为准。行业统计方面优先取当地官方统计机构与国际组织数据；行业协会数据须先确认其统计口径与编制方法。

涉及中国台湾地区上市主体的，表述须规范，数据来源以当地交易所等披露平台为准，引用时同样适用上述五项对齐要求。

## 二级来源清单

二级来源须具备可溯源的发布机制，即报告本身标明编制方法、数据口径与编制机构。具备下列特征的，可归入二级。

| 类别 | 举例 | 使用条件 |
|---|---|---|
| 公开招投标数据 | 政府采购网、公共资源交易平台、医疗机构招标公告的中标结果 | 可追溯至具体项目公告的，按二级使用；聚合平台提供的统计须注明平台名称与统计方法 |
| 行业协会统计 | 全国性、有固定统计口径与定期发布的行业协会数据 | 须注明协会全称、统计期间、指标定义 |
| 券商研究报告 | 具备证券投资咨询业务资格的机构发布的行业与个股研究 | 仅用于获取行业数据与可比公司名单，不引其投资评级与目标价 |
| 专业数据库 | Wind、同花顺 iFinD、Choice 等 | 须注明数据库名称、取数日期、具体字段 |
| 国际组织与境外官方机构 | 世界银行、国际货币基金组织、经合组织、各国央行与统计机构 | 用于跨境比较与时点判断，须注明指标定义与基准年 |
| 外资可比公司披露 | 境外上市公司的年报（如 10-K）与业绩发布材料 | 用于跨国同业对照，须以原始披露文件为准 |

**二级来源涉及财务数据的，必须与一级来源交叉核对。** 核对不一致时以一级来源为准，并在数据来源表中记录差异。

## 三级来源的处置

三级来源包括：新闻门户与财经媒体的报道、自媒体文章、社交平台帖子、问答社区内容、百科条目、未经署名的转载。

处置规则有三条。

第一，三级来源只用于发现线索。例如从媒体报道中得知某公司发生了一笔收购，随后须到巨潮资讯网下载该收购的公告原件。

第二，凡从三级来源获得的信息，若无法回一级或二级来源核实，一律标注为"未核实"，不进入正文的论证，只能在数据来源表中列示为存疑项。

第三，媒体的分析性判断（如"该公司护城河深厚""行业景气度回升"）不得引用。分析性结论必须由本技能依据原始数据自行推导。

## 明确禁止的来源

下列内容不得作为数据来源或论据，任何情形下都不例外：

- 无明确署名与发布主体的网络文章、论坛帖、评论区内容
- 内容由算法生成、未标明信源的信息聚合页
- 付费荐股群、投资社群、直播荐股提供的"内部消息"与"消息面"
- 未经核实的传闻、小道消息、"知情人士"转述
- 篡改、拼接原始披露的二次加工内容
- 以广告或引流为目的的软文
- 已过时且无更新机制的数据（如以三年前数据描述当期状况，且未见后续更新）

## 估值数据的来源与算法

估值数据属时点数据，来源与算法须同时标注，否则数值无从复核。

| 数据项 | 取得方式 | 层级 |
|---|---|---|
| 收盘价与总市值 | 交易所个股行情页 | 一级 |
| 归母净利润与净资产 | 定期报告，用于自行计算倍数 | 一级 |
| 市盈率、市净率等倍数 | 行情数据供应商 | 二级 |
| 历史分位区间 | 由上述倍数序列自行计算 | 二级 |

**倍数可由一级数据自行计算时，应自行计算并注明计算式**（如市值除以滚动十二个月归母净利润，并写明所用净利润的起止期间）。自行计算可避免不同供应商口径不一致，也便于读者复核。

分位须标明算法与区间。历史分位取自家五至十年区间，须写起算年份；同业分位取同群对照组的横截面，名单须与三步追问法第二步所用名单一致。**两种分位的含义不同，不得笼统称为"估值分位"。**

涉及估值须以当次检索所得的行情为准，不得沿用历史对话中的数据。报告须标注取数日期，未标日期的倍数在发布后即失去意义。

## 标注要求

研报中的每条数据都须在数据来源表中登记，字段包括：

| 字段 | 说明 |
|---|---|
| 数据项 | 该数字或事实的简要描述 |
| 数值／口径 | 具体数值，并注明口径（如"营业收入，合并报表，全年累计"） |
| 来源层级 | 一级／二级／三级 |
| 来源名称 | 发布主体与文件全称 |
| 发布或披露日期 | 精确到日 |
| 定位 | 页码、表格编号、公告编号或网址 |
| 状态 | 已核实／待核实／未核实 |

正文引用时采用简称标注（如"据 2025 年年度报告"），完整信息在来源表中给出。简称只写文件名称，不在正文中标层级，层级信息只在来源表体现。

**正文中不得出现无来源的数字。** 确实需要作定性判断而无数据支撑时，改为不使用数字的表述。

### 层级标注的两个易错点

**未取得原件的，层级不得标为一级。**

一级来源指公司定期报告与法定公告本身。若数据系经媒体报道、数据库或行业研究转述获得，无论内容是否出自定期报告，层级一律标二级。

层级描述的是数据的权威出处与本报告的获取途径，不是内容的原始出处。仅当实际取得原件、且能在来源表中写出页码或表格编号时，方可标一级。**做不到就下标一级**，这一类错标是来源表最容易出的问题，因为它表面上抬高了可信度，实际上使整张表失去溯源的用处。

遇到这种情形的规范做法是：层级标二级，来源名称写实际渠道（如署名媒体或数据库），定位列写明该渠道的上游出处（如"报道转述自 2025 年年度报告"）。

**层级与核实状态是两件事。** 层级说明数据的权威程度，状态说明核实到了哪一步。二级来源经两个以上相互独立且具名的主体交叉一致者，状态可标已核实，但层级仍为二级。

## 数据质量三态

| 状态 | 定义 | 在研报中的位置 |
|---|---|---|
| 已核实 | 来自一级来源原件；或来自二级来源，且经两个以上相互独立且具名的主体交叉一致 | 可进入正文论证 |
| 待核实 | 来自二级来源且仅有单一渠道，未获交叉印证；或来自三级来源但已找到指向一级来源的线索 | 可进入正文，但须在数据来源表标注，并列入风险提示的数据边界 |
| 未核实 | 仅见于三级来源，无一级或二级来源可对应 | 不得进入正文，只能在数据来源表中列示为存疑项 |

**不得用推测填补缺失数据。** 某一指标查不到时，写明"未获取该数据"，并说明该缺失对结论的影响范围。

### 待核实数据的使用限度

待核实数据可以进入正文，但不得成为核心结论的唯一支撑。判断办法是：把该项数据整体删除后，主要判断是否仍然成立。

若不成立，须从下列三项中选择其一处理。其一，补做核实，将其升级为已核实。其二，调整结论的表述强度，改为条件式表述，例如"该项数据若得到确认，则结论为……"。其三，在正文中以弱化语气交代来源，例如"据公开信息转述"。

**风险提示中不得笼统声称"该缺失不影响结论方向"。** 这一断言必须逐项说明：哪个结论依赖待核实数据、依赖到什么程度、核对结果与之不符时结论如何变化，以及哪些结论不依赖待核实数据。

研报的页脚声明"未核实信息不作为论据"时，须注意"未核实"与"待核实"是两个不同的状态。若正文使用了待核实数据，页脚声明不得使读者误以为正文全部数据均已核实，宜改为"所引数据均标注来源与核实状态，核实状态见数据来源表"。

## 检索操作要点

- 检索时同时使用公司全称与股票代码，避免与同名主体混淆
- 财务数据一律以原始报告为准，不使用二手汇总（含财经网站的数据页）
- 注意口径差异：区分"境内／境外"与"国内／海外"，区分"营业收入"与"主营业务收入"，区分"归母净利润"与"净利润"
- 统一时间窗口：对比时使用同一报告期，跨期比较须说明口径变化
- 注意计量单位：年报常用"元"，须与"万元""亿元"换算一致后再引用
- 涉及汇率换算的数据，须注明所用汇率与换算时点

## 可信度的判断原则

数据来源的层级比数据的数量更重要。一份只使用一级来源、结论克制的研报，比一份堆砌大量二级与三级来源、结论激进的研报更可靠。

遇到同一事实存在多个来源且彼此不一致时，处理顺序为：以一级来源为准；一级来源之间不一致时，采用最新披露且注明差异；仅二级来源时，采用发布主体权责最明确者并标注；仅三级来源时，不采用。
