# 数据采集清单

分析一家公司时按本清单检索。带 ★ 者为必查项，缺失将导致结论缺乏支撑。来源的层级判定与使用条件见 `source-policy.md`。

## 公司基本情况

| 项目 | 说明 | 来源 | 层级 |
|---|---|---|---|
| ★ 主营业务构成 | 分行业／分产品的收入、成本、毛利率 | 年报"主营业务分行业情况" | 一级 |
| ★ 各业务占比与增速 | 用于识别底盘 | 同上，自行计算 | 一级 |
| 行业地位 | 全球／国内排名、市场占有率 | 年报"行业情况"、行业协会统计 | 一级／二级 |
| 主要产品与客户 | 产品线、客户类型与集中度 | 年报、公司公告 | 一级 |

## 财务数据

| 项目 | 说明 | 来源 | 层级 |
|---|---|---|---|
| ★ 营业收入 | 当期与同比 | 年报／半年报／季报 | 一级 |
| ★ 归母净利润 | 当期与同比 | 同上 | 一级 |
| ★ 经营活动现金流净额 | 验证利润质量 | 现金流量表 | 一级 |
| 毛利率 | 变化方向与幅度 | 利润表 | 一级 |
| 期间费用与费用率 | 观察投入节奏 | 利润表 | 一级 |
| 财务费用与汇兑损益 | 出口型企业必查 | 利润表及附注 | 一级 |
| 研发投入及占比 | 观察投入强度 | 年报 | 一级 |
| 应收账款与周转 | 观察收入质量 | 资产负债表 | 一级 |
| 存货 | 观察供需状况 | 资产负债表 | 一级 |
| 商誉 | 并购形成的风险敞口 | 资产负债表、审计报告关键审计事项 | 一级 |
| 有息负债与偿债指标 | 观察财务安全边际 | 资产负债表 | 一级 |

**利润与现金流的关系须单独说明。** 利润下降而现金流改善，表明经营质量提升；利润良好而现金流欠佳，表明收入可能包含较多应收账款。两者须合并观察方有意义。

## 行业特征（★ 必查）

在分析公司之前先建立行业参照。缺少行业层面数据时，后文关于"属行业性还是个体性"的判断将失去依据。逐项核对下列维度，取不到数据的须在报告"分析覆盖范围"中声明，不得沉默跳过。

| 维度 | 说明 | 主要来源 | 层级 |
|---|---|---|---|
| ★ 市场规模与增长率 | 行业容量、增速、是否接近饱和 | 行业协会统计、同行业公司招股说明书 | 二级 |
| ★ 行业盈利水平及趋势 | 平均毛利率与净利率的区间及近年走势 | 同行上市公司定期报告横向汇总、行业协会 | 一级／二级 |
| ★ 行业生命周期阶段 | 导入、成长、成熟或衰退 | 招股书行业概况章节、券商行业研究 | 二级 |
| ★ 集中度 | CR5 等指标，判断竞争格局 | 招股书竞争格局章节、行业协会 | 二级 |
| 进入与退出壁垒 | 资质认证、资本开支、渠道门槛、客户转换成本 | 招股书行业概况 | 二级 |
| 成本与技术特征 | 原材料价格机制、自动化程度、产品同质化程度 | 招股书、公司公告 | 一级／二级 |
| 规模经济与范围经济 | 单位成本曲线的形态、产线复用能力 | 公司公告、招股书募集资金用途 | 一级／二级 |
| 产能利用情况 | 行业产能利用率、公司产销率 | 公司定期报告产销量表 | 一级 |
| 纵向整合程度 | 行业内是否向上游或下游延伸 | 公司公告、行业研究 | 一级／二级 |
| 资源需求与供应状况 | 主要原料的供应格局与价格传导机制 | 官方统计、行业协会 | 一级／二级 |
| 客户需求与条件 | 下游客户集中度与议价能力 | 公司定期报告、招股书 | 一级 |
| 产品技术特征与主要参与者 | 主要参与者名单、产品差异程度 | 招股书、行业协会 | 二级 |
| 竞争者数量与分布 | 竞争者数量、地域分布与梯队 | 招股书、券商行业研究 | 二级 |

**同行业公司的招股说明书是性价比最高的行业数据来源。** 招股书必含"行业概况"与"竞争格局"两章，覆盖市场规模、集中度、壁垒与主要参与者等多项，数据翔实且公开免费。检索方式为"公司名称＋招股说明书"，或经巨潮资讯网按公司检索其首发文件。

## 同群对照（★ 必查）

至少选取一到两家可比公司，以相同时间窗口对照。

**对照对象的选取依据**：同行业、同经营模式、同收入来源结构。优先选取市场公认的可比公司（证券研究报告披露的"可比公司"列表可直接采用），其次选取收入体量相近者。

**须查证的指标**（两家公司须查证同一组指标，口径不一致则无法比较）：

| 项目 | 用途 |
|---|---|
| 营业收入同比 | 判断行业需求端的变化 |
| 归母净利润同比 | 判断行业利润端的变化 |
| 境外收入占比 | 判断汇率与关税风险的暴露程度 |
| 毛利率及变化 | 判断成本端压力的普遍性 |

**三种对照结果对应三种判断**：

| 对照结果 | 判断 |
|---|---|
| 可比公司利润同样下降 | 压力属行业性，非目标主体经营失误 |
| 可比公司收入增长而目标主体下降 | 需求端问题出在目标主体自身 |
| 可比公司收入下降而目标主体增长 | 行业承压期目标主体份额提升，基本盘稳固（最易被忽略的正面信号） |

**该步骤不可省略。** 缺少同群对照，则无法判断外部因素的解释力，全文归因将失去依据。实际案例中，同群对照常同时给出两个方向的结论，例如行业利润普遍下降（外部成因）与目标主体收入逆势增长（自身能力），仅查证单一主体无法得出该类结论。

| 项目 | 说明 | 来源 | 层级 |
|---|---|---|---|
| 管理层对经营形势的判断 | 对未来一段时期的预期 | 投资者关系活动记录表 | 一级 |
| 既定目标 | 具体的量化目标 | 年报、公告 | 一级 |
| 资本开支方向 | 资金投向 | 现金流量表、公告 | 一级 |
| 并购与整合 | 标的情况与整合进展 | 公告 | 一级 |

## 数据质量标注

采集时对每条数据标注状态。判定标准见 `source-policy.md`。

| 状态 | 定义 | 在研报中的位置 |
|---|---|---|
| 已核实 | 出自一级来源，或二级来源且已与一级来源交叉核对一致 | 可进入正文论证 |
| 待核实 | 出自二级来源尚未交叉核对，或三级来源但已找到指向一级来源的线索 | 可进入正文，须在来源表标注并列入风险提示 |
| 未核实 | 仅见于三级来源，无一级或二级来源可对应 | 不得进入正文，仅在来源表中列为存疑项 |

**最终交付的研报中，"未核实"与"待核实"均须如实标注。** 这一处理较虚构数值更为稳妥，也是分析可信度的来源。数据缺失时写明"未获取该数据"，并说明该缺失对结论的影响范围。

## 检索操作要点

- 检索时同时使用公司全称与股票代码，避免与同名主体混淆
- 财务数据一律以原始报告为准，不使用二手汇总（含财经网站的数据页）
- 注意口径差异：区分"境内／境外"与"国内／海外"，区分"营业收入"与"主营业务收入"，区分"归母净利润"与"净利润"
- 统一时间窗口：对比时使用同一报告期，跨期比较须说明口径变化
- 注意计量单位：年报常用"元"，须与"万元""亿元"换算一致后引用
- 涉及汇率换算的数据，须注明所用汇率与换算时点
- 聚合平台提供的统计数据，须注明平台名称与统计方法，并按二级来源处理

## 交付前的数据核对

| 核对项 | 要求 |
|---|---|
| 来源层级 | 每条数据标注一级／二级／三级 |
| 交叉核对 | 二级来源的财务数据已与一级来源核对并记录差异 |
| 正文数字 | 无无来源数字 |
| 缺失数据 | 已如实标注，未以推测填充 |
| 来源表字段 | 数据项、数值／口径、层级、来源名称、日期、定位、状态七项齐备 |
