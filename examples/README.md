# 示例说明

本目录收录两份完整产出样例，用于说明方法在实际分析中的呈现效果。两份均通过本技能的交付自检。

## mindray-300760-risk-report.html

**分析对象**：迈瑞医疗（深交所 300760），综合医疗器械企业，业务覆盖生命信息与支持、体外诊断、医学影像与新兴业务。

**报告日期**：2026-09-20　**数据截止**：2026 年半年度报告

### 这份示例展示什么

**三板产线结构下的底盘识别。** 体外诊断占比升至 38.68%，其试剂收入随装机持续复购，构成底盘。报告据此说明底盘的判定依据（体量、黏性、现金流三项）。

**双支柱的收入结构。** 国际收入占比 53%，国内占 47%。2025 年境内下降 22.97% 时由境外承接，是理解该公司抗风险能力的入口。

**结论随数据更新而修正。** 基于 2025 年年报时判断为结构性风险，补入 2026 年中报后改为过渡期风险。依据是营收已恢复正增长、第二季度归母净利润转正、剔除汇兑损益后增速更高。这一变化本身说明了跨报告期数据的价值。

**同群对照的口径切换。** 图 3 可在营收同比与归母净利润同比之间切换，用于同时展示"利润同向下滑"与"收入方向分化"两个结论。

**行业环境章。** 含市场容量、行业盈利水平与集中度、成本与技术特征、规模经济、客户结构五个方面，并补入体外诊断集采的行业背景数据。

## halters-002615-risk-report.html

**分析对象**：哈尔斯（深交所 002615），不锈钢保温器皿制造企业，以境外品牌客户代工为主要收入来源。

**报告日期**：2026-09-18　**数据截止**：2026 年半年度报告

### 这份示例展示什么

**结算端风险的识别。** 该公司收入以美元计价而成本以人民币发生，净利率仅 2.76%，汇率变动通过低净利率结构放大为利润的大幅波动。结算端是出口导向型企业的必查项。

**外生冲击与主动投入的区分。** 与迈瑞不同，该公司的利润收缩来自汇率这一完全不可控的外生变量，而非主动投入。两份示例对照可看出同一方法在不同成因下的判断差异。

**低集中度行业的竞争优势来源。** 行业 CR4 不足 20%，产能与产业链协同是行业公共品而非公司专属优势，报告的护城河判断据此展开。

**四类交互元素与二级来源标注。** 与迈瑞示例相同。

### 关于来源标注

两份示例的层级均标注为二级。原因是数据通过公开渠道检索获得，未取得定期报告原件。迈瑞示例的定位列记录到具体渠道与上游出处；哈尔斯示例产出较早，渠道未逐条留存原始链接，来源名称按渠道类型概述，已在该报告的数据来源节中说明。

## 使用须知

示例中的数据与判断均为公开信息基础上的方法演示，**不构成任何投资依据**。其中的「待核实」项未经与定期报告原件逐项核对，具体数值可能调整。

示例涉及的第三方公司数据均来自各公司公开披露，引用仅为方法说明之用。
