# 示例说明

本目录收录一份完整产出样例，用于说明方法在实际分析中的呈现效果。该样例通过本技能的交付自检。

## mindray-300760-risk-report.html

**分析对象**：迈瑞医疗（深交所 300760），综合医疗器械企业，业务覆盖生命信息与支持、体外诊断、医学影像与新兴业务。

**报告日期**：2026-09-20　**数据截止**：2026 年半年度报告

### 这份示例展示什么

**三板产线结构下的底盘识别。** 体外诊断占比升至 38.68%，其试剂收入随装机持续复购，构成底盘。报告据此说明底盘的判定依据（体量、黏性、现金流三项）。

**双支柱的收入结构。** 国际收入占比 53%，国内占 47%。2025 年境内下降 22.97% 时由境外承接，是理解该公司抗风险能力的入口。

**结论随数据更新而修正。** 基于 2025 年年报时判断为结构性风险，补入 2026 年中报后改为过渡期风险。依据是营收已恢复正增长、第二季度归母净利润转正、剔除汇兑损益后增速更高。这一变化本身说明了跨报告期数据的价值。

**同群对照的口径切换。** 图 3 可在营收同比与归母净利润同比之间切换，用于同时展示"利润同向下滑"与"收入方向分化"两个结论。

**行业环境章。** 含市场容量、行业盈利水平与集中度、成本与技术特征、规模经济、客户结构五个方面，并补入体外诊断集采的行业背景数据。

**估值参照。** 列示市盈率的三个口径与取数时点、历史分位与同业分位，再把当前价格反推为经营假设，与过渡期风险的判断对照，给出「定价偏悲观」的结论并说明该差异不构成买入理由。其中一项同业横截面未能识别发布主体，按来源规范列为未核实、不进入论证，可用于说明来源分级规则的实际执行方式。

**外部资料与市场观点辑录。** 该附录收录管理层自 2024 年至 2026 年的表述演变、监管与主管部门文件、五家机构或汇总口径的观点、一条个人投资者观点，以及四个时点的市场反应。这一节是隔离区，只列不评，其他章节不得回引，报告结论也不建立在其上。三处细节可以说明规范的实际执行：三个因缺发布日期而未能收录的券商目标价在附录中如实说明；综合目标价出现 217.85 元与 249.50 元两个不一致的数值，按规范并列并说明分歧；市场反应一条因某平台前复权序列与未复权口径不一致而弃用该平台数据，并在脚注写明验算方式。

### 关于来源标注

该示例的层级标注为二级。原因是数据通过公开渠道检索获得，未取得定期报告原件。定位列记录到具体渠道与上游出处，数据来源表七个字段齐备。

层级与核实状态是两个独立维度：层级衡量来源的权威程度，核实状态表明已核对到哪一步。两者的定义见 `references/source-policy.md`。

## 使用须知

示例中的数据与判断均为公开信息基础上的方法演示，**不构成任何投资依据**。其中标注为「待核实」的项目未经与定期报告原件逐项核对，具体数值可能调整。

示例涉及的第三方公司数据均来自各公司公开披露，引用仅为方法说明之用。
