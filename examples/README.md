## halters-002615-risk-report.html

**分析对象**：哈尔斯（深交所 002615），不锈钢保温器皿制造企业，以境外品牌客户代工为主要收入来源。

**报告日期**：2026-09-18　**数据截止**：2026 年半年度报告

### 这份示例展示什么

**三步追问法的完整推演。** 收入来源部分识别出底盘为客户关系而非品牌；风险敞口部分定位到结算端（汇率）为首要压力来源；可转换性部分判断为"换得动但慢"。

**同群对照的两个方向结论。** 报告选取嘉益股份与同富股份作对照。利润端三家同步下降，说明利润压力属行业性；收入端哈尔斯与同富保持增长而嘉益收缩，说明哈尔斯在行业承压期份额未失。两个方向的结论合并，才把行业性问题与个体性问题分开。

**四张图表的配置方式。** 收入构成环形图、净利率与财务费用对比图、公司与可比公司分组柱状图、主业与替代路径体量对照图，分别对应四类判断。每张图表下方三行标注齐备。

**数据来源追溯。** 文末来源表登记十六项数据，逐项标注层级与核实状态。其中七项标注为"待核实"，均为二级来源转述或推算值。这一处理方式说明了规范在实际操作中如何落地。

### 使用须知

报告中的数据与判断均为公开信息基础上的一次方法演示，**不构成任何投资依据**。

其中的"待核实"项未经与年度报告逐项核对，具体数值可能调整。若需将本报告内容用于实际决策，须先完成数据核对。
